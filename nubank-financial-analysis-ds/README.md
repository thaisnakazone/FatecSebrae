# Nubank Financial Analysis DS

Projeto de Ciência de Dados desenvolvido na disciplina da Fatec Sebrae.

## Estrutura
- /data → dados brutos e processados
- /src → scripts de coleta, feature engineering, modelagem e visualização
- /notebooks → notebooks exploratórios
- /reports → relatórios e apresentações

## Objetivo
Modelagem preditiva e análise estratégica do Nubank (2021–2025), incluindo:
- Forecast de receita e margem
- Simulação de cenários de risco
- Sensibilidade a variáveis macroeconômicas
- Benchmark setorial
